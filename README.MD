# Text Editor
This text editor is build with WPF upon MVC architecture demonstrating State, Command and Memento pattern. This project was meant for Software Patterns cource in uni.

## Commands
- Insert text
- Copy
- Cut
- Delete
- Open file 
- Paste
- Redo
- Save file
- Undo 

## States
- Highlighing
- Insert
- Overwrite
- ReadOnly

## Memento Pattern
- History Manager
- Model for history manager

User can do all commands written above. User can use mouse and keyboard binding for excetuting commands.
